# 初めに
Pokect8086という`V30`CPUを搭載した復刻機を用いて`8080`用機械語を動かす環境を整えていきます。
`V30`は日本電気が製造していたCPUで、基本的には`8086`CPUの互換機ですが、`8086`とは違い、8bitCPU`8080`の機械語にも対応しています。

Pokect8086は`8080`向けの設計ではなく、あくまでも搭載している`V30`が偶然`8080`に対応していただけなので周辺機器との通信をする際は`8086`モードへ返る必要があります。
そこで`8086`のコードをBIOS的に使用して、Pokect8086で`8080`がまともに動くようにしていくことを目的としています。
